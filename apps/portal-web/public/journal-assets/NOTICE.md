# Journal image provenance and permission boundary

## Scope and release status

Arum requested the existing Freedom Fieldnotes template, including its six member avatars, be transferred to the platform module on 2026-10-23. That contributor instruction covers this requested journal display and maintenance; it is not evidence of every reference image's authorship or subject consent, and it is not a blanket MIT image licence.

**On 2026-10-23, in direct response to the reference-source/creator question, Arum confirmed: “人像是我創作的” (“I created the portraits”). This is the contributor authorship attestation for the portraits listed below, read together with the existing journal transfer/display instruction. Maintainer review is still pending; this record does not assert independent verification of every reference or separate subject consent, and does not itself approve deployment.** All PNGs in this directory are public static assets when deployed: an unpublished article, an unassigned editor, or an absent API key does not quarantine them. This notice is a release blocker record, not an access control.

Only the final illustrated avatars below are included. Reference photos, private source documents, prompts, consent documents and older portrait variants are not included. Private rights evidence must be reviewed privately; do not add it to this public repository. A public URL or a matching hash proves source/version, not permission.
