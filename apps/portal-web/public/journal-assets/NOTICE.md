# Journal image provenance and permission boundary

These assets were imported from Arum's authored Freedom Fieldnotes site at the user's explicit request to preserve the entire existing template and its six public member portraits in the platform module.

- `freedom-mark-v2.png`, `mist-background.png`, `shared-workshop.png`: existing journal design assets, copied unchanged.
- Six SHA-256 named PNG files: the six portraits referenced by the previously authorized public website edition. Each filename was checked against the image bytes. Only referenced public files were copied; private portraits and alternate snapshots were excluded.
